# 一键收集 Windows 崩溃日志

保持 App 的“VirtIO 显示设备”关闭，只开启“挂载驱动／日志盘”，再自行启用 JIT、启动 Windows。

在“此电脑”打开 `WINIOSDRV` 盘，双击 **一键收集日志.cmd**，权限提示选择“是”。出现“日志收集完成”后，回复“已收集”即可；不用复制文字或截图。

工具读取最近的蓝屏／异常关机事件、显示设备、驱动和崩溃转储设置；最多复制三份、每份不超过 8MiB 的已有小型转储，并读取已有 MEMORY.DMP 的前 64KiB。不会复制整个内存转储，不安装驱动、不改注册表、不重启 Windows。没有崩溃转储时也会保存事件记录及错误说明。

输出在同盘 `CRASHLOGS`。我会从 iPad 的工具盘镜像读取这些文件，在本机分析，不将崩溃记录上传到 GitHub。
